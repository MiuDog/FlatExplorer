# 使用 Obsidian Sync 傳送套件

適用於已經使用 Obsidian Sync、並已在電腦安裝 FlatExplorer 的使用者。無須為了安裝套件另外購買同步服務；沒有使用 Sync 時，優先選擇 [BRAT](README.md)。

1. 確認電腦與手機／平板連接同一個遠端 Vault，並使用預期的設定資料夾。
2. 在每個裝置分別開啟「設定 → Sync → Vault configuration sync」中的 **Installed community plugin list**，讓套件檔案與設定可同步。
3. 若也要同步啟用狀態，啟用 **Active community plugin list**；若希望各裝置自行決定啟用哪些套件，可不開此項，並在手機／平板手動啟用 FlatExplorer。
4. 等待傳輸完成，完全關閉再重新開啟手機／平板的 Obsidian。

各裝置的 Sync 選項需分別設定，不會自動互相同步。若使用不同設定資料夾，例如 `.obsidian-mobile`，需確認接收的是該設定檔，不能假設電腦 `.obsidian` 的套件會自動出現在另一個設定資料夾。

以上依 [Obsidian 官方設定同步文件](https://obsidian.md/help/sync/settings) 整理。
